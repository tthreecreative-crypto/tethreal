te.threal planner

Kebijakan Privasi

Diperbarui 26 November 2026 · tethreal.site

te.threal planner adalah aplikasi perencana konten media sosial. Halaman ini menjelaskan data apa yang kami simpan dan bagaimana data Google Anda dipakai.

Data akun

Saat mendaftar, kami menyimpan nama, email, dan status persetujuan akun Anda. Isi planner (judul konten, caption, jadwal, target, ide, template, data live, dan angka report) disimpan di database Supabase dalam sebuah workspace. Isi workspace hanya bisa diakses oleh anggota workspace tersebut yang akunnya sudah disetujui admin. Pemilik workspace menentukan siapa yang diundang.

Data Google

Jika Anda memilih menghubungkan Google, aplikasi meminta dua izin:

  • Google Calendar (calendar.events): untuk membuat, memperbarui, dan menghapus acara jadwal konten yang Anda buat di planner, serta menampilkan acara kalender Anda di tampilan kalender planner.
  • Google Drive (drive.file): untuk menyimpan dan membaca file cadangan planner, serta menyimpan file yang Anda upload sendiri lewat aplikasi (video, gambar carousel, dan screenshot report) ke folder "te.threal planner – Uploads" di Drive Anda. Aplikasi hanya bisa mengakses file yang dibuatnya sendiri dan tidak bisa melihat file lain di Drive Anda.

File yang Anda upload diatur agar siapa pun yang memiliki link dapat melihat, supaya anggota workspace bisa membuka dan mengunduhnya. Link tersebut hanya ditampilkan di dalam workspace. Anda bisa mengubah pengaturan berbagi atau menghapus file kapan saja langsung dari Google Drive.

Untuk menjaga sambungan tetap aktif, kami menyimpan token akses Google (refresh token) secara terenkripsi di server kami. Token ini hanya dipakai untuk menjalankan fitur di atas atas permintaan Anda, tidak dibagikan ke pihak lain, tidak dijual, dan tidak dipakai untuk iklan atau melatih model AI.

Penggunaan informasi yang diterima dari Google API mematuhi Google API Services User Data Policy, termasuk ketentuan Limited Use.

Link approval

Anggota workspace bisa membuat link approval untuk atasan atau klien. Siapa pun yang memegang link tersebut bisa melihat konten pada periode yang dipilih (judul, caption, jadwal, dan file) lalu memberi tanggapan, tanpa perlu login. Nama dan catatan yang diisi peninjau disimpan bersama konten. Link berlaku sesuai masa yang dipilih dan bisa dinonaktifkan kapan saja.

Screenshot untuk report

Saat Anda meng-upload screenshot Insights untuk report Instagram atau TikTok, atau screenshot insight per postingan, angka dibaca langsung di browser Anda memakai pustaka pembaca teks (Tesseract.js) yang dimuat dari jsDelivr. Isi screenshot tidak dikirim ke server kami untuk dibaca. Screenshot hanya disimpan jika Google Anda terhubung, yaitu di Google Drive Anda sendiri.

Menghapus data

Anda bisa memutus sambungan Google kapan saja lewat menu Data & Integrasi → Putuskan; token akan dicabut dan dihapus dari server. Anda juga bisa mencabut akses di pengaturan akun Google. Untuk menghapus akun dan seluruh data planner, hubungi admin.
